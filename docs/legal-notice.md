## Verifying a source

The server provides a collected snapshot for research. Preserve the source URL and collection timestamp. For legal or compliance decisions, check the effective Korean text directly on the [KRX Legal Portal](https://rule.krx.co.kr/out/index.do). If a collected link has expired, locate the document by title or ID. English versions, snippets and converted tables or formulas are aids to locating the source. The project does not provide legal advice.

## Public source policy

Public responses provide bounded Markdown and source metadata such as title, ID, URL, filename, media type and collection time when available. An `official_source` descriptor can help reopen a KRX source in a fresh portal session. Original binary files and local preservation paths stay on the server.

Any separate service distributing binaries must establish redistribution rights, authenticate downloads, limit their size and allow only approved file types and signatures.
